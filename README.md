Entry for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun.

`main.py` writes one funny line (124 characters, within the 1–140 gate)
to `/output/entry.txt`:

> I told my smart speaker a secret, and now every ad knows it. Honestly, it's the first time anyone has really listened to me.

Run it with:

```sh
python3 main.py
```

The line is deterministic and baked into `main.py` — no network, no
external reads. The script asserts the 1–140 character gate before
writing and verifies the written file by reading it back.
